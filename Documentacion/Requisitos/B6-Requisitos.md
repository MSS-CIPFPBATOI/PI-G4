| Código | Requisito | Necesidad que cubre | Prioridad |
|---|---|---|---|
| **RF-01** | El sistema deberá permitir la autenticación centralizada de los usuarios. | Gestión centralizada de cuentas, roles y control de acceso. | **Alta** |
| **RF-02** | El sistema deberá permitir la gestión de documentos centralizados de expedientes, informes y proyectos. | Centralizar documentos económicos, técnicos y de certificación. | **Alta** |
| **RF-03** | El sistema deberá automatizar el almacenamiento y registro de las pruebas del laboratorio. | Automatizar procesos de laboratorio y reducir errores manuales. | **Alta** |
| **RF-04** | El sistema deberá tener una aplicación web de empresa para los trabajadores. | Comunicación interna, avisos, horarios y gestión laboral. | **Media** |
| **RF-05** | El sistema deberá permitir la gestión de clientes y solicitudes al equipo comercial. | Centralizar datos de clientes y optimizar el flujo comercial. | **Media** |
| **RF-06** | El sistema deberá controlar el inventario y los movimientos del almacén en tiempo real. | Organizar maquinaria, repuestos y materiales de trabajo. | **Media** |
| **RF-07** | El sistema deberá guardar los accesos de visitas e incidencias de seguridad. | Gestionar la recepción y la vigilancia de la empresa. | **Baja** |
| **RF-08** | El sistema deberá proporcionar un acceso remoto seguro. | Facilitar el teletrabajo y la conexión entre sedes de forma cifrada. | **Alta** |
| **RF-09** | El sistema deberá supervisar en tiempo real los servidores, redes y la infraestructura. | Monitorizar fallos informáticos. | **Alta** |
| **RF-10** | El sistema deberá hacer copias de seguridad programadas de datos y servicios. | Proteger información crítica ante desastres o pérdida de datos. | **Alta** |
| **RNF-01** | La infraestructura de red deberá estar segmentada con VLANs. | Proteger el tráfico de red, organización lógica y aislamiento de entornos. | **Alta** |
| **RNF-02** | Los servicios críticos deberán tener mecanismos de tolerancia a fallos. | Garantizar la alta disponibilidad de los sistemas de la empresa. | **Alta** |
| **RNF-03** | La arquitectura de hardware y software deberá ser escalable. | Permitir la ampliación de sedes, puestos de trabajo y volumen de datos sin rediseño. | **Media** |
| **RNF-04** | Los datos sensibles deberán ser cifrados en el envío y en reposo. | Proteger certificaciones, expedientes e información económica. | **Alta** |
| **RNF-05** | Toda la infraestructura deberá estar documentada de forma profesional. | Facilitar la administración, auditorías e intervenciones del departamento informático. | **Media** |
